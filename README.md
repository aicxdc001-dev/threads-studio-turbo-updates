# Threads Studio Turbo

Bản mới nhất: **3.0.1**.

## Cập nhật các bản từ 05/11/2026 lên 3.0.1

Trong tool chọn **Tùy chọn → Kiểm tra cập nhật → Cập nhật ngay**. Tool tự tải, kiểm tra SHA-256, sao lưu, cài và mở lại 3.0.1. Giữ nguyên key, API key, đăng nhập, bố cục và dữ liệu. Không cần file kích hoạt riêng hay chọn lại thư mục.

Hỗ trợ 2.3.1-vieneu.2, .3; 2.3.2-vieneu.1 đến .19; và Turbo 3.0.0. Các phiên bản cũ được phục vụ bằng gói tương thích ở kênh cũ. Máy đã lên 3.0.1 được bỏ qua, không tải hoặc cài lại. Các gói Turbo đã thành công ngày 20/11 được giữ nguyên. Sau khi lên 3.0.1, tool dùng kênh Turbo này và tự kiểm tra bản mới khi mở. Khi có bản mới, bấm Cập nhật ngay.

## Trường hợp cần file hỗ trợ

Bản 3.0.1 cũ chưa bật cập nhật online hoặc bộ cài đã bị chỉnh kênh có thể dùng file **ThreadsStudio-Turbo-CapNhat-3.0.1.exe** trong Releases. Đóng tool, chọn thư mục đang dùng và cập nhật một lần. Đây là phương án hỗ trợ; Turbo 3.0.0 chính thức có thể cập nhật trực tiếp bằng nút trong tool.

Các tệp trong Releases là bản cập nhật cho bộ tool đã cài đầy đủ, dùng lại Chromium và VieNeu hiện có. Không cần tài khoản GitHub để tải. Không đăng dữ liệu cá nhân, cookie, API key hoặc công cụ cấp key lên kho này.
